# Renderer Web Client

Web version of `dicom_viewer`, built with React, TypeScript, and Vite.

Current scope:

- Local WebGL2 rendering
- Folder-based loading for uncompressed 16-bit DICOM series
- Axial, coronal, sagittal, and volume views
- Persisted Local/Remote and WebGL/WebGPU settings
- Remote and WebGPU modes reserved for later implementation

## Development

```powershell
npm.cmd install
npm.cmd run dev
```
